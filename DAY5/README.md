## Key Highlights 🚀

### Properties 📏

- `length`: Determines the number of characters in a string.

### Methods Without Arguments ⚙️

- `toUpperCase()` 🔠: Converts the string to uppercase.
- `toLowerCase()` 🔡: Converts the string to lowercase.
- `trim()` ✂️: Removes whitespace from both ends of a string.
- `trimStart()` ↔️: Removes whitespace from the start.
- `trimEnd()` ↔️: Removes whitespace from the end.

### Methods With Arguments 🛠️

- `includes()` ✅: Checks if a substring exists within a string.
- `indexOf()` 🔍: Finds the index of a specified substring.
- `replace()` 🔄: Replaces a part of the string.
- `replaceAll()` 🔁: Replaces all matching substrings.
- `concat()` ➕: Concatenates strings.
- `padStart()` ⬅️: Pads the string at the start.
- `padEnd()` ➡️: Pads the string at the end.
- `charAt()` 🅰️: Retrieves a character at a specific index.
- `charCodeAt()` 🔢: Gets the ASCII code of a character.
- `split()` 🧩: Splits a string into an array.
- `substring()` ✨: Extracts a portion of a string.
- `slice()` 🔪: Extracts a portion of a string (supports negative indexes).
