String Methods and Properties

Firstly, the Strings in JavaScript are indexed. So basically this simply means one can easily access any single character of any String using it's indice or position value. See below we can do something like this!

Expression: 'Hello World'[2]
Result: 'l'


**There's only a single property which exists**

Property

So, basically Property of String can be accessed or utilized with the help of a simple-single . notation!

  • length

Methods

As there's actually a one Property as others are almost methods or can say functions of any String Object created!!

And there are two types of Methods overall

Methods (Without Argument)

  • toUpperCase()
  • toLowerCase()
  • trim()
  • trimStart()
  • trimEnd()

Methods (With Argument)

Arguments: Here mean one has to to provide something as an input in-order to get an desired output.

**Note: If Arguments ain't provided by the user then, the method might not return an appropriate output resulting to an un-wanted result in the end**

  • includes()
  • indexOf()
  • replace()
  • replaceAll()
  • concat()
  • padStart()
  • padEnd()
  • charAt()
  • charCodeAt()
  • split()
  • substring()
  • slice()
