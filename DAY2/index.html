Let's firstly dive into Primitive!

Primitive data-types are basic fundamental level and low level data-types in JavaScript
  1. string
  2. number
  3. boolean
  4. bigInt
  5. null
  6. undefined
  7. symbol

To check the type of data just use typeof operator!

NOTE: typeof null would result in Object. So better use existingVariable === null to check if it's null or not

NOTE there's only one Non-Primitive Data type i.e., Object
