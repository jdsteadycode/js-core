### Data Types in JavaScript

Welcome to the DAY2 folder of the `js-core` repository! In this section, we explore the fundamental building blocks of data in JavaScript: primitive data types.

## Overview

JavaScript has several primitive data types that represent single values. These types are immutable, meaning that their values cannot be changed once they are created. Understanding these data types is crucial for effective programming in JavaScript.

## Primitive Data Types

Here are the six primitive data types in JavaScript:

1. **String**
   - Represents a sequence of characters.
   - Example: 
     ```javascript
     const greeting = "Hello, World!";
     ```

2. **Number**
   - Represents both integer and floating-point numbers.
   - Example: 
     ```javascript
     const age = 25;
     const temperature = 98.6;
     ```

3. **Boolean**
   - Represents a logical entity and can have two values: `true` or `false`.
   - Example: 
     ```javascript
     const isJavaScriptFun = true;
     ```

4. **Undefined**
   - Indicates a variable that has been declared but has not yet been assigned a value.
   - Example: 
     ```javascript
     let myVariable;
     console.log(myVariable); // Output: undefined
     ```

5. **Null**
   - Represents the intentional absence of any object value.
   - Example: 
     ```javascript
     const emptyValue = null;
     ```

6. **Symbol** (introduced in ES6)
   - Represents a unique identifier and is often used as a key for object properties.
   - Example: 
     ```javascript
     const uniqueID = Symbol('id');
     ```

## Conclusion

Understanding these primitive data types is essential for mastering JavaScript. They are foundational for working with variables, functions, and data structures.
