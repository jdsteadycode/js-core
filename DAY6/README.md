#### **Math Object in JavaScript 🔢**

This project explores the **Math Object** in JavaScript, a built-in static object that allows us to perform a wide range of mathematical operations without creating an instance. The examples included in this project demonstrate the use of various mathematical operators, properties, and methods available in the `Math` object.

---

## **🌟 Introduction**

The `Math` object in JavaScript provides several properties and methods for performing mathematical tasks. It is **static**, meaning its properties and methods are directly accessible without creating an object instance.

---

## **✨ Features**

- Covers common mathematical operators:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
  - Remainder (`%`)
  - Exponentiation (`**`)
- Explains key properties of the `Math` object.
- Demonstrates important methods like:
  - `Math.sqrt()`
  - `Math.pow()`
  - `Math.floor()`
  - `Math.ceil()`
  - `Math.round()`
  - `Math.random()`

---

## **📐 Some Properties of Math Object**

1. **`Math.PI`** - The value of π (approximately 3.14).
2. **`Math.SQRT2`** - Square root of 2 (approximately 1.41).

---

## **🔧 Methods of Math Object**

1. **`Math.sqrt(param)`**: Returns the square root of the input.
2. **`Math.pow(param1, param2)`**: Raises `param1` to the power of `param2`.
3. **`Math.floor(param)`**: Rounds the input down to the nearest integer.
4. **`Math.ceil(param)`**: Rounds the input up to the nearest integer.
5. **`Math.round(param)`**: Rounds the input to the nearest integer.
6. **`Math.random()`**: Generates a random decimal between `0` (inclusive) and `1` (exclusive).
