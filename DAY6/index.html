Math in JavaScript

is built-in Object which is static by nature. Hence allows to access it's properties `n` methods without creating instance

i.e., Math.property

It allows to us to perform Mathematical tasks or operations on number*

Mathematical Operators

  • Addition Operator: +
  • Subtraction Operator: -
  • Multiplication Operator: *
  • Division Operator: /
  • Remainder Operator: %
  • Exponent Operator: **

Properties of Math Object

  • Math.PI
  • Math.SQRT2
  • Math.E

Methods of Math Object

  • Math.sqrt(param)
  • Math.pow(param1, param2)
  • Math.floor(param)
  • Math.ceil(param)
  • Math.round(param)
  • Math.random()

Infinity and -ve Infinity are keywords in JavaScript when some thing is divided by 0.

TYPE: number

Example: -8 / 0 gives -Infinity
