#### 🚀 Comparison Operators in JavaScript

This project demonstrates the usage of **Comparison Operators** in JavaScript. It includes an `index.html` file for a brief explanation and a `script.js` file for practical demonstrations. ✨

## 📂 Files

- 📜 **index.html** - Provides an overview of JavaScript comparison operators.
- 📜 **script.js** - Contains JavaScript code demonstrating how comparison operators work.

## 🔍 Operators Covered

### ✅ **Equality Operators**

- `==` ➝ Simple Equality (Allows type conversion) 🔄
- `===` ➝ Strict Equality (No type conversion) 🚫
- `!=` ➝ Simple Not Equal ❌
- `!==` ➝ Strict Not Equal 🛑

### 🔢 **Relational Operators**

- `>` ➝ Greater than 🔼
- `<` ➝ Less than 🔽
- `>=` ➝ Greater than or equal to 🟢
- `<=` ➝ Less than or equal to 🔵

## 🎯 Key Highlights

✔️ Tells how JavaScript **implicitly converts** data types when using `==`.  
✔️ Demonstrates why `===` is **preferred** for accurate comparisons.  
✔️ Includes **explicit type conversion** techniques for better understanding.

## 🚀 How to Run

1. **Open** `index.html` in a web browser. 🌍
2. **Open the Console** (`F12` → `Console` in Chrome) to see the results from `script.js`. 🖥️

## 📌 Example Output

```javascript
console.log("222" == 222); // ✅ true (due to implicit type conversion)
console.log("222" === 222); // ❌ false (strict type checking)
console.log(225 > "222"); // ✅ true (string converted to number)
```
