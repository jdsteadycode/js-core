TRUTHY AND FALSY VALUES IN JAVASCRIPT 🤯

List of Falsy ❎ values:

  • false - Boolean type
  • NaN - Not A Number
  • O - Zero
  • -0 - Minus Zero
  • On - BigInt Zero
  • "", '', `` - Empty & template String
  • null - null object
  • undefined - undefined type

Except above everything is Truthy ✅Some of them shown below:

  • true - Boolean type
  • {} - empty Object
  • [] - empty Array
  • -Infinity - Negative Infinity
  • Infinity - Positive Infinity
  • -1 - Any Negative Integer (EX: 1)
  • 303 - Any Positive Integer (EX: 303)
  • "0" - Any String containing anything (EX: 0)
