#### **❕❔ DAY 14: Learning Ternary Operator in JavaScript 🎯**

This project demonstrates optimized decision-making by implementing ternary-operator in JavaScript. 🚀

---

## 📌 Contents

- **Ternary-Operator** – Using `(condition/ expression) ? <true code> : <false code>` block to handle multiple conditions.
- **Optimization** – Unlike `if-else` the ternary-operator `? :` works best for single condtions saving up lines of code and execution-time.
- **Truthy & Falsy Values** – How `? :` works is that it's similar to `if-else` block as it also evaluates condtion/ expression as `Truthy & Falsy Values`.
- **Debugging Execution** – Used `debugger` keyword or Developer Tools (`Sources`) Tab for execution flow.

## 🚀 How to Run

1. **Open** `index.html` in a web browser. 🌍
2. **Open the Console** (`F12` → `Console` in Chrome) to see results from `script.js`. 🖥️

## ⚡ How it Works?

**The ternary-operator `? :` block checks for the `true` condition if found then it instantly goes with `?` block of code else, it executes `:` block of code accordingly**

- `["admin", "staff].includes("admin")` → current user is `admin` 🥷🏽
- `["male", "female"].includes("female")` → current user's `gender` is 👩🏻‍💼

## 🚀 Performance Advantage

Unlike the `if-else` statements, ternary-operator`? :` has,

- ✅ less code
- ✅ faster as only two parts `?` or `:` (primarily\*)
- ✅ More optimized and readable/ clear decision-making logic.

## 🛠 Debugging / Execution Guide

- Use `debugger` keyword to pause script execution.
- Open Developer Tools (`F12` → Sources Tab) to analyze code execution step-by-step.

## 📸 Preview (Output)

```bash
------------------

Enter name? jeet
Enter gender? Male
Enter role? admin
------------------

jeet 🧑🏻‍💼, you're logged-in as admin
```
