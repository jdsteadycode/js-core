#### **🔥 DAY 10: Decision Making in JavaScript (IF Statement) 🎯**

This project contains practice exercises and explanations for **Decision Making** using `if` statement in JavaScript.

---

## 📌 Contents

- **`IF` Statement** – Executes a block of code only if a condition is true.
- **Dialog-box `prompt()`** – to get user data.
- **Built-in function `parseInt()`** – to sanitize input by converting strings and numbers.
- **Setting Default Values** – Assigned `Guest` & `20` if input was empty.
- **Multi-line IF Execution** – Used `{}` to execute multiple statements.
- **Performance Drawback** - JS still checks all IFs even if one matches!
- **Debugging/ Testing** - Used `debugger` keyword or can explicitly see in sources tab to see how code executes based on condition!

## 🚀 How to Run

1. **Open** `index.html` in a web browser. 🌍
2. **Open the Console** (`F12` → `Console` in Chrome) to see the results from `script.js`. 🖥️

## ⚡ How it works?

**1️⃣** User is asked to enter a name & age.
**2️⃣** JS validates the input and assigns defaults if missing.
**3️⃣** IF statements check the age and print results:

- 18-24 → College Student 🏫
- 25-40 → Working Professional 💼
- 40+ → Retired Professional 🏡

## 📸 Preview (Output)

```bash
Enter Name? Karun
Enter Age? 23
NAME: Karun & AGE: 23
Karun is a college student
```

## **📂 Files**

- `index.html` → Displays information about `if` Statement.
- `script.js` → Contains code demonstrating the code execution handled by decision making using `if`.

🚀 Run it in your browser and check the console!
