#### **🔢 DAY 9: Logical Operators in JavaScript**

This project contains practice exercises and explanations for **Logical Operators** (`&&`, `||`, `!`) in JavaScript. Logical operators are used for decision-making and evaluating multiple conditions.

---

## 🔍 Contents

- **Logical AND (`&&`)** – Returns the first falsy value or the last truthy value.
- **Logical OR (`||`)** – Returns the first truthy value or the last falsy value.
- **Logical NOT (`!`)** – Negates a boolean value.
- **Truthy & Falsy Values** – Understanding how non-boolean values behave in logical operations.
- **Hands-on Exercises** – Test your understanding with practical examples.

## 🚀 How to Run

1. **Open** `index.html` in a web browser. 🌍
2. **Open the Console** (`F12` → `Console` in Chrome) to see the results from `script.js`. 🖥️

## ⚡ Quick Examples

```javascript
console.log(100 && 0); // Output: 0 (Falsy)
console.log(-Infinity || -0); // Output: -Infinity (Truthy)
console.log(!-0); // Output: true
```

## **📂 Files**

- `index.html` → Displays information about Logical Operators.
- `script.js` → Contains code demonstrating various logical operations and exercises.
