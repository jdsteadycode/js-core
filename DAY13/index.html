🤘🏻 Switch-case Control Statement in JavaScript

Better Alternative of if Statement🎯

switch allows to execute the code based on various conditions given.

i.e., it selects one of matching case and then executes it's code-block present!

Work?

1. value given inside switch() ➡ [matches]

2. with the appropriate case & if match found then it executes the underlying code and goes out of the whole Switch-Control block!
