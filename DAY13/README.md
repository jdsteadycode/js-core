#### **💼 DAY 13: Learning Switch Statements in JavaScript 🎯**

This project more decision-making more optimized by implementing switch-case in JavaScript. 🚀

---

## 📌 Contents

- **Switch-Case** – Using `switch-case` block to handle multiple conditions.
- **Logical Flow Optimization** – Unlike `if-else` the JS Engine instantly exits the `switch-case` block once the case is matched to switch `value`.
- **if-else block to switch-case** – converted `if-else` block code → `switch-case` as an example.
- **Truthy & Falsy Values** – How `switch` works is that it doesn't care about the `value` whether it's `truthy` or `falsy` It justs strictly checks for the equality.
- **Debugging Execution** – Used `debugger` keyword or Developer Tools (`Sources`) Tab for execution flow.

## 🚀 How to Run

1. **Open** `index.html` in a web browser. 🌍
2. **Open the Console** (`F12` → `Console` in Chrome) to see results from `script.js`. 🖥️

## ⚡ How it Works?

**The `switch-case` block checks for the matching `true` with `case` and then returns result accordingly**

- `0-4` → Kid playing 🎈
- `5-17` → School student learning 📚
- `18-24` → College student (Computer Science) 💻
- `25-55` → Working professional (JavaScript learner) 🔥
- `56-120` → Retired person reading newspaper 📰
- `< 0 or > 120` → Invalid age warning ⚠

## 🚀 Performance Advantage

Unlike the `if-else` statements, `switch-case` has,

- ✅ JS stops checking conditions once as it directly jumps to the matching `case's value`, making it faster!
- ✅ Strictly checks for the equality i.e., `===` with `case value` and `switch(value)`.
- ✅ More optimized and readable/ clear decision-making logic.
